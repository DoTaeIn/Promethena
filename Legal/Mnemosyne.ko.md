## 1. 한 줄 요약

**Mnemosyne는 계정을 만들지 않고, 학습 자료 내용을 운영자 서버로 전송하지 않는 로컬 데스크톱 앱입니다.** PDF, 녹음, OCR 결과와 검색 인덱스는 이용자의 Windows 컴퓨터에 저장됩니다.

## 2. 저장하는 정보

Mnemosyne는 서비스를 제공하기 위해 다음 정보를 이용자 컴퓨터에만 저장합니다.

| 항목 | 내용 | 저장 위치 |
|---|---|---|
| 프로필 이름 또는 별칭 | 첫 실행 시 이용자가 입력한 표시 이름 | `%LOCALAPPDATA%\Bookworm\profile.json` |
| 프로젝트 정보 | 프로젝트 이름, 과목·학기, 색상, 생성 시각 | `%LOCALAPPDATA%\Bookworm\projects.json` |
| 가져온 자료 | 원본 PDF 또는 ZIP, ZIP에서 추출한 페이지 이미지·오디오 | `%LOCALAPPDATA%\Bookworm\books\…` |
| 처리 결과 | PDF 텍스트, OCR 텍스트, 음성 전사문, 검색용 벡터와 SQLite 검색 인덱스 | `%LOCALAPPDATA%\Bookworm\books\…`, `index.sqlite3` |

이 정보는 앱 기능을 제공하기 위한 것이며, 운영자가 열람하거나 광고·분석·모델 학습에 사용하지 않습니다.

## 3. 네트워크 통신

Mnemosyne의 사용자 화면과 처리 엔진은 같은 컴퓨터의 `127.0.0.1`(loopback)에서만 통신합니다. 이 통신은 컴퓨터 밖으로 나가지 않으며, 가져온 자료와 검색어는 운영자 서버로 전송되지 않습니다.

임베딩 모델은 로컬에 이미 있는 파일만 사용합니다. 다만 음성 인식에 필요한 모델이 기기에 없다면, 사용 중인 음성 인식 라이브러리가 해당 공개 모델 파일을 내려받을 수 있습니다. 이때 자료·녹음·검색어의 내용은 보내지 않지만, 모델 제공자는 일반적인 다운로드 연결 정보(예: IP 주소)를 처리할 수 있습니다. 모델이 준비된 뒤의 OCR·전사·검색 처리는 로컬에서 수행됩니다.

Mnemosyne는 운영자 서버, 계정 인증, 분석 도구, 광고 SDK, 오류 수집 도구를 사용하지 않습니다.

## 4. 보관과 삭제

데이터는 이용자가 삭제할 때까지 해당 컴퓨터에 보관됩니다.

- 앱에서 **문서 삭제**를 선택하면 그 문서의 원본, 추출 페이지·오디오, OCR·전사 결과와 검색 데이터를 삭제합니다.
- 앱에서 **프로젝트 삭제**를 선택하면 프로젝트에 속한 모든 문서와 그 검색 데이터를 삭제합니다.
- 앱을 제거해도 사용자 데이터 폴더는 자동으로 삭제되지 않을 수 있습니다. 완전한 삭제를 원하면 `%LOCALAPPDATA%\Bookworm` 폴더를 직접 삭제할 수 있습니다.

삭제는 현재 기기의 로컬 저장소를 대상으로 하며, Mnemosyne가 운영하는 원격 복사본은 존재하지 않습니다.

## 5. 제3자 제공과 권한

Mnemosyne는 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 앱은 이용자가 고른 파일을 읽고, 사용자 데이터 폴더에 처리 결과를 쓰기 위한 파일 접근만 사용합니다. 카메라, 마이크, 위치, 연락처, 브라우저 기록 또는 다른 계정 정보에는 접근하지 않습니다.

## 6. 이용자의 권리

이용자는 앱 안에서 자료와 프로젝트를 직접 삭제할 수 있으며, 위 저장 위치의 데이터를 직접 열람·수정·삭제할 수 있습니다. 계정이나 운영자 서버에 저장되는 이용자 데이터가 없으므로 별도의 계정 삭제 절차는 없습니다.

## 7. 만 14세 미만

Mnemosyne는 만 14세 미만 아동을 대상으로 하지 않습니다. 계정이나 원격 개인정보 수집 기능은 없지만, 미성년자의 자료 사용은 보호자와 교육기관의 지침을 따라야 합니다.

## 8. 정책의 변경

향후 외부 서버 전송, 계정 기능, 분석 도구 또는 추가 권한이 도입되면 해당 기능을 배포하기 전에 이 문서를 먼저 갱신합니다. 변경 사항은 게시 시점부터 적용됩니다.
