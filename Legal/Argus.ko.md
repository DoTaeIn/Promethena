## 1. 요약

Argus는 웹사이트 운영자가 자기 사이트의 방문 데이터를 직접 수집·분석하는 도구입니다.
따라서 이 문서는 두 종류의 정보를 나눠서 설명합니다.

- **Argus 계정 정보** — Argus를 사용하는 운영자 본인의 정보입니다. 우리가 직접 관리합니다.
- **방문자 이벤트 데이터** — 고객사 웹사이트의 방문자 데이터입니다. **이 데이터의 처리자는
  고객사이고, 우리는 고객사의 위탁을 받아 저장·처리하는 수탁자입니다.**

## 2. Argus 계정 정보

| 항목 | 목적 | 보관 |
|---|---|---|
| 이메일 주소 | 로그인, 필수 안내 | 탈퇴 후 30일 |
| 이름 | 화면 표시 | 탈퇴 후 30일 |
| 비밀번호 | 로그인 | 탈퇴 후 30일 |
| 세션 토큰 | 로그인 유지 | 만료 즉시 삭제 |
| 접속기록 | 법령상 안전조치 의무 | 1년 |

비밀번호는 원문을 저장하지 않고 일방향 해시로만 보관합니다.

## 3. 방문자 이벤트 데이터

고객사가 자기 사이트에 Argus SDK를 설치하면 아래 항목이 우리 서버로 전송됩니다.

| 항목 | 설명 |
|---|---|
| 익명 식별자 | 브라우저마다 부여되는 임의 값 |
| 사용자 식별자 | **고객사가 직접 지정한 값.** 우리가 만들지 않습니다 |
| 세션 식별자 | 방문 단위 구분용 |
| 페이지 주소·경로 | 어떤 화면을 봤는지 |
| 유입 경로(referrer), UTM 파라미터 | 어디서 들어왔는지 |
| 이벤트 이름과 속성 | 고객사가 정의한 행동 기록 |

**수집하지 않는 것** — IP 주소, User-Agent, 화면 해상도, 브라우저 언어, 기기 지문(fingerprint)을
수집하지 않습니다. 광고 네트워크에 데이터를 제공하지 않으며, 여러 고객사의 데이터를 합쳐
개인을 추적하지 않습니다. 프로젝트별 데이터는 서로 격리됩니다.

**보관** — 24개월이 지난 이벤트는 삭제합니다.

**고객사와의 관계** — 방문자 데이터에 대한 열람·정정·삭제 요청은 해당 웹사이트의 운영자
(고객사)에게 해주셔야 합니다. 우리는 고객사의 지시에 따라 처리하며, 계약이 종료되면 데이터를
반환하거나 파기합니다.

## 4. 제3자 제공

수집한 데이터를 판매하거나 광고 목적으로 제공하지 않습니다. 자사(first-party) 수집 도구라는
점이 이 제품의 존재 이유입니다.

## 5. 이용자의 권리

Argus 계정 보유자는 본인 정보의 열람·수정·삭제를 요청할 수 있습니다. 방문자 데이터에 대한
권리 행사는 3항의 안내를 따라주세요.

## 6. 만 14세 미만

Argus는 만 14세 미만 아동을 대상으로 하지 않습니다.

## 7. 정책의 변경

수집 항목이 늘어나면 이 문서를 먼저 갱신합니다. 특히 IP 주소나 User-Agent 수집을 추가하려면
이 문서를 고친 뒤에 배포합니다.
