# Argus

Argus는 사용자가 제품을 어떻게 이용하는지, 신뢰할 수 있는 데이터로 명확하게 이해하려는 팀을 위한 퍼스트파티 제품 분석 플랫폼입니다.

브라우저 행동을 구조화된 이벤트로 수집하고, 익명 방문자가 로그인하면 기존 행동까지 동일 사용자로 연결합니다. 이어서 핵심 지표와 이벤트 탐색기로 결과를 정확하고 간결하게 보여줍니다.

## 할 수 있는 일

- 가벼운 브라우저 SDK로 페이지 조회, 클릭, 폼 제출, 세션, UTM 정보를 자동 수집합니다.
- 방문자의 네트워크가 끊겨도 이벤트를 브라우저에 임시 보관하고 연결이 복구되면 전송합니다.
- 프로젝트 단위 이벤트 ID로 재전송된 이벤트를 한 번만 집계합니다.
- 로그인 이후 익명 방문자를 사용자 ID에 연결하고, 로그인 전 행동도 함께 병합합니다.
- 최근 7일의 이벤트, 방문자, 세션, 구매 수와 방문자 추이를 대시보드에서 확인합니다.
- 이벤트명, 익명 ID, 사용자 ID, 세션, 발생 시각, 속성으로 이벤트를 탐색하고 검색합니다.

## 책임 있는 분석을 위한 설계

Argus는 브라우저 수집 키와 비공개 관리 키를 분리하고, 승인된 Origin에서만 수집 요청을 받습니다. API 키와 세션 토큰은 원문이 아닌 해시로 저장하며, 토큰이나 개인정보가 실수로 담길 수 있는 URL 쿼리스트링은 수집하지 않습니다.

현재 베타에는 로그인 워크스페이스, 서버 측 프로젝트 범위 제한, CSP와 브라우저 보안 헤더, 로그인 시도 제한, CSRF 방어를 위한 Origin 검증, PostgreSQL 영속 저장이 포함됩니다.

## 로컬 실행

```sh
docker compose up --build -d
docker compose exec api node src/migrate.mjs
docker compose exec api node src/seed.mjs
```

`.env.example`을 바탕으로 `.env`를 만들고 모든 예시 비밀값을 교체한 뒤, `http://localhost:8787/app`에서 데모를 열 수 있습니다.

## 상태

Argus는 베타 단계입니다. 트래킹 엔진, 로그인, 대시보드, 이벤트 탐색기는 동작합니다. 프로덕션 고도화 단계에서는 MFA, 이메일 검증·복구, 분산 Rate Limit, 감사 로그, 동의 관리, 퍼널·리텐션 같은 고급 분석을 추가할 예정입니다.
