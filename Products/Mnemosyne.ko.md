# Mnemosyne

Mnemosyne는 강의 PDF와 녹음 파일을 한곳에 모아, 인터넷 계정이나 서버 업로드 없이 내 컴퓨터에서 검색할 수 있게 해 주는 Windows 데스크톱 앱입니다.

자료를 가져오면 PDF 페이지를 읽고 OCR 텍스트와 검색 인덱스를 로컬에 만듭니다. 프로젝트별로 자료를 정리한 뒤, 여러 PDF와 강의 음성에서 함께 내용을 찾을 수 있습니다.

## 핵심 기능

- **강의 자료 가져오기:** PDF 또는 이미지·오디오가 든 ZIP 파일을 프로젝트에 추가합니다.
- **로컬 OCR와 검색:** 페이지 텍스트를 인식하고, 키워드와 의미 기반 검색을 함께 사용합니다.
- **강의 음성 처리:** 녹음 파일을 추가해 음성을 텍스트로 찾을 수 있습니다.
- **프로젝트별 정리:** 과목·학기별 프로젝트 안에서 자료를 관리하고 통합 검색합니다.
- **근거로 이동:** 검색 결과에서 관련 PDF 페이지로 바로 이동하고 텍스트 강조 표시를 확인합니다.
- **로컬 우선 개인정보:** PDF, 녹음, OCR 결과, 검색 인덱스는 외부 서버로 전송하지 않습니다.

## 사용 흐름

1. Mnemosyne를 실행하고 이름 또는 별칭을 입력합니다.
2. 강의 프로젝트를 만든 뒤 PDF 또는 ZIP 자료를 추가합니다.
3. 자료 처리가 끝날 때까지 기다립니다.
4. 프로젝트 검색창에서 개념, 문장, 주제를 찾습니다.
5. 결과를 선택해 해당 PDF 페이지를 확인하거나 강의 음성을 추가합니다.

## 개인정보과 저장 위치

Mnemosyne는 계정을 요구하지 않습니다. 학습 자료와 처리 결과는 기본적으로 Windows의 `%LOCALAPPDATA%\Bookworm`에 저장됩니다. 문서나 프로젝트를 삭제하면 관련 원본 자료와 검색 데이터도 함께 삭제됩니다.

## 베타 상태와 제한 사항

현재 버전은 Windows 10/11용 비공개 베타입니다. 첫 자료 처리에는 시간이 걸릴 수 있으며, 기본 업로드 제한은 파일당 1GB입니다. ZIP 파일은 이미지와 오디오만 지원하고, 손상되었거나 과도하게 압축된 파일은 안전을 위해 거부합니다. 코드 서명 전 빌드에서는 Windows SmartScreen 경고가 표시될 수 있습니다.
