# Chronos

수강신청에서 중요한 것은 버튼을 대신 눌러주는 자동화가 아니라, 내가 직접 클릭할 순간을 놓치지 않는 것입니다.

Chronos는 현재 페이지의 서버 시각, 네트워크 왕복시간(RTT), 지터, 사용자의 반응속도를 측정해 개인화된 권장 클릭 타이밍을 보여주는 Chrome 확장 프로그램입니다. 목표 시각을 설정하면 마지막 10초를 카운트다운하고, 권장 시점에 화면과 소리로 신호를 보냅니다.

## 핵심 기능

- **서버 시각 추정:** 페이지의 HTTP `Date` 응답과 왕복 지연을 이용해 로컬 시계와 서버 시각의 차이를 추정합니다.
- **네트워크 상태 측정:** 여러 RTT 표본의 중앙값과 지터를 계산해 안정·주의·불안정 상태를 표시합니다.
- **반응속도 보정:** 5회의 클릭 테스트로 사용자의 반응시간을 측정하고 브라우저 로컬 저장소에 보관합니다.
- **스마트 트리거:** 반응속도, 네트워크 편도 지연 추정치, 안전 보정값을 합산해 목표 시각보다 조금 앞서 신호를 냅니다.
- **집중 카운트다운:** 목표 시각 10초 전부터 큰 숫자로 카운트다운을 표시합니다.
- **로컬 우선:** 측정값과 설정은 외부 서버로 전송하지 않습니다.

## 사용 흐름

1. 수강신청 페이지에서 Chronos를 엽니다.
2. 서버 시각과 네트워크 상태가 측정될 때까지 기다립니다.
3. 필요하면 반응속도 영점 조절을 실행합니다.
4. 목표 시각을 입력하고 카운트다운을 시작합니다.
5. 신호가 오면 사용자가 직접 신청 버튼을 클릭합니다.

## 안전한 범위

Chronos는 신청 버튼 클릭, 폼 제출, 반복 요청, CAPTCHA나 대기열 우회를 자동으로 수행하지 않습니다. 계산 결과는 성공을 보장하는 시간이 아니라, 현재 환경에서 더 나은 클릭 타이밍을 찾기 위한 참고값입니다.

## 현재 상태와 다음 단계

현재 버전은 별도 빌드가 필요 없는 Manifest V3 MVP입니다. 대학별 사이트 어댑터, 신뢰도와 오차 범위 표시, 접근성 중심 알림 모드, 실전 결과 기반 개인화 보정, 자동화된 테스트를 다음 단계로 계획하고 있습니다.
